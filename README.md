📊 Параллельное умножение матриц (OpenMP)
📌 Описание проекта

Проект реализует параллельное умножение квадратных матриц с использованием технологии OpenMP на языке C++.

Дополнительно реализован Python-скрипт для проверки корректности вычислений с использованием библиотеки NumPy.

📁 Структура проекта
.
├── ConsoleApplication2.cpp   # Основная программа (OpenMP)
├── verify.py                 # Скрипт проверки результатов
├── experiment_results.txt    # Таблица времени выполнения
├── verification_reports.txt  # Отчёт проверки
├── matrix_a_<N>.txt          # Матрица A
├── matrix_b_<N>.txt          # Матрица B
├── matrix_c_<N>.txt          # Результат умножения
└── README.md                 # Документация
⚙️ Компиляция и запуск
🔧 Компиляция (MSVC)
cl /openmp ConsoleApplication2.cpp
▶️ Запуск
ConsoleApplication2.exe
🚀 Что делает программа

После запуска программа:

Генерирует случайные матрицы A и B
Сохраняет их в файлы
Выполняет параллельное умножение (OpenMP)
Замеряет время выполнения
Сохраняет результат C
Формирует таблицу результатов
🧠 Реализация параллелизма

Умножение выполняется с использованием директивы:

#pragma omp parallel for

Параллелится внешний цикл по строкам матрицы.

📏 Размеры тестов

Эксперименты проводятся для размеров:

200, 400, 800, 1200, 1600, 2000
📊 Результаты экспериментов

Результаты сохраняются в файл:

experiment_results.txt

Формат:

| Размер | Время |
|-------|-------|
| 200 | 0,022867 |
| 400 | 0,207917 |
| 800 | 1,491654 |
| 1200 | 5,638400 |
| 1600 | 24,685155 |
| 2000 | 47,161530 |
✅ Проверка корректности

Для проверки используется скрипт:

python verify.py
🔍 Что делает verify.py:
Загружает матрицы из файлов
Вычисляет эталон:
np.matmul(A, B)
Сравнивает с результатом программы:
np.allclose(...)
Выводит результат проверки
Сохраняет отчёт
📄 Отчёт проверки

Создаётся файл:

verification_reports.txt

Содержит:

размер матрицы
статус (OK / ERROR)
использованные файлы
📈 Анализ производительности

Алгоритм имеет сложность:

O(N³)

📦 Генерируемые файлы

Во время работы создаются:

matrix_a_<N>.txt
matrix_b_<N>.txt
matrix_c_<N>.txt
experiment_results.txt
verification_reports.txt

⚠️ Все файлы должны находиться в одной директории с verify.py
