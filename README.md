# Параллельное умножение матриц (OpenMP, C++)

## Описание проекта

В данной работе реализован алгоритм умножения квадратных матриц с использованием технологии параллельного программирования OpenMP на языке C.

Программа выполняет следующие задачи:
- генерация случайных матриц заданного размера
- выполнение операции умножения матриц
- измерение времени выполнения вычислений
- сравнение производительности при различном числе потоков
- вычисление ускорения (Speedup)
- сохранение полученных результатов в файл
---

##  Анализ результатов

- Для матриц небольшого размера (200–400) применение параллелизма не приводит к ускорению.
Это связано с тем, что накладные расходы на управление потоками превышают выигрыш от распараллеливания.
- Для матриц среднего размера (800–1200) наблюдается умеренное ускорение.
Прирост производительности составляет до 10%.

- Для матриц большого размера (1600–2000) достигается наибольший эффект от параллелизации.
Максимальное ускорение составляет около 20%.

###  Вывод:
Параллельное умножение матриц с использованием OpenMP становится эффективным только при достаточно больших объёмах вычислений.
При малых размерах задач накладные расходы нивелируют преимущества параллельного выполнения.

---

## Причины ограниченного ускорения
Ограниченная эффективность параллелизации обусловлена следующими факторами:
- накладные расходы на создание и синхронизацию потоков
- ограниченная пропускная способность оперативной памяти
- низкая локальность данных (cache misses)
