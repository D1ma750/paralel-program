# Параллельное умножение матриц

Данный проект реализует параллельное умножение квадратных матриц с использованием технологии OpenMP на языке C++.

Также в проекте присутствует Python-скрипт для проверки корректности вычислений с использованием библиотеки NumPy.

# Структура проекта

```
.
├── ConsoleApplication2.cpp        # Основная программа (OpenMP)
├── verify.py                 # Скрипт проверки
├── experiment_results.txt    # Результаты экспериментов
├── verification_reports.txt   # Отчёт проверки
├── matrix_a_<N>.txt          # Матрица A
├── matrix_b_<N>.txt          # Матрица B
├── matrix_c_<N>.txt          # Результат умножения
└── README.md                 # Документация
```

# Компиляция и запуск

##  Компиляция программы

Используется компилятор **MSVC** с поддержкой OpenMP:

```bash
cl /openmp ConsoleApplication2.cppp
```
---

##  Запуск программы

```bash
ConsoleApplication2.exe
```

После запуска программа:

1. Генерирует случайные матрицы A и B
2. Сохраняет их в файлы
3. Выполняет параллельное умножение матриц
4. Измеряет время выполнения
5. Сохраняет результат C
6. Формирует таблицу результатов

---

## 3️ Проверка корректности результатов

Для проверки используется Python-скрипт:

```bash
python verify.py
```

Что делает verify.py:

1. Загружает матрицы из файлов
2. Вычисляет эталонный результат:

```python
np.matmul(A, B)
```

3. сравнивает результаты:

```python
np.allclose(C_ref, C_prog, atol=1e-6)
```
4. Выводит статус проверки
5. Сохраняет отчёт в файл **verification_reports.txt**

# Анализ производительности

Теоретическая сложность алгоритма:

```
O(N³)
```

Наблюдения:

* При увеличении размера матрицы **в 2 раза** время увеличивается примерно **в 8 раз**.
* Это соответствует теоретической сложности `O(N³)`.
* На больших размерах матриц появляются отклонения из-за:

  * ограничений **кеш-памяти процессора**
  * затрат на **доступ к памяти**
  * особенностей **параллельного выполнения**
 * График зависимости Времени от объема матрицы
